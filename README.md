# 📚 E-Learning Management System (Android)

A native Android application developed using **Kotlin** that provides an interactive learning platform for students and administrators. The application offers subject-based learning through video lessons, quizzes, progress tracking, and role-based access control. Administrators can manage learning content, while students can complete lessons and monitor their learning achievements.

---

# ✨ Features

## 👨‍🎓 Student Features

* User Registration and Login
* Subject Selection

  * Mathematics
  * English
  * General Knowledge (GK)
* Browse Chapters and Lessons
* Watch Educational Videos
* Multiple Choice Quizzes
* Instant Quiz Feedback
* Progress Tracking
* Star Reward System
* Profile Dashboard
* Help & Support
* Secure Logout

---

## 👨‍💼 Admin Features

* Admin Login
* Dashboard Management
* Create New Learning Content
* Update Existing Lessons
* Delete Learning Content
* View Service Logs
* Manage Subject Categories
* Secure Logout

# 🚀 Getting Started

## Prerequisites

* Android Studio
* Android SDK
* Kotlin
* Android Emulator or Physical Android Device

## Installation

Clone the repository

```bash
git clone https://github.com/NewBieZz12/Android-Studio-Kotlin-E-learning-Management-System-Daily-Study.git
```

Open the project in Android Studio.

Build the project and allow Gradle to download all required dependencies.

Run the application on an emulator or Android device.

---

# 🗄️ Database

The application uses **SQLite** as the local database.

The database stores:

* User Accounts
* Roles (Admin / Student)
* Subjects
* Lessons
* Educational Services
* Learning Progress
* Quiz Information

The system supports full CRUD operations for educational content management.

# 📖 Learning Modules

The application provides learning resources for three subjects:

* 📐 Mathematics
* 📖 English
* 🌍 General Knowledge (GK)

Each subject contains:

* Chapters
* Video Lessons
* Practice Exercises

Students earn rewards after successfully completing quizzes.
